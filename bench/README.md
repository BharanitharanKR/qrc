# bench

Benchmark corpus and profiling harness (Phase 0). This will hold the corpus definition
(`corpus.toml`: workspaces pinned to exact commits and toolchains), the driver scripts that run
each scenario, and committed result summaries under `results/`. Raw traces go to
`results/raw/`, which is git-ignored.

See [docs/phase-0.md](../docs/phase-0.md). Empty for now.
